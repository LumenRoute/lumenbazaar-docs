# Code Of Conduct

LumenBazaar follows a contributor covenant based on respect, clarity, and practical collaboration.

## Expected Behavior

- Keep discussion focused on the work.
- Review ideas and code on technical merit.
- Be direct without being hostile.
- Respect maintainers, contributors, users, and reviewers.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private information without permission.
- Deliberately misleading project users about security, funding, or network status.
- Repeated off-topic disruption.

## Enforcement

Maintainers may moderate issues, discussions, pull requests, and repository access to protect the project.
