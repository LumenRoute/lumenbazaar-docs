# LumenBazaar Docs

This repository contains the public documentation site for LumenBazaar, a Stellar-native x402 facilitator and Bazaar discovery layer.

## Local Development

```bash
npm install
npm run start
```

## Checks

```bash
npm run lint
npm run links
npm run build
```

## Repository Role

The docs repo is the canonical source for architecture, guides, API references, contract references, SDK references, operations, security, funding, and contributor workflows.
